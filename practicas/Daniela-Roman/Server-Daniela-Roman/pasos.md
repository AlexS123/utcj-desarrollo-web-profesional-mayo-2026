Crear el servidor

1.- Iniciar servidor
    - npm init
2.- Instalar dependencias (express, dotenv, mongoose, bcrypt, cors):
    - npm i express dotenv mongoose bcrypt cors
3.- Agregar carpetas:
    - /public 
    - /models
    
4.- Agregar archivos:
    - /.env
    - /app.js
    - /public/index.html
    - /models/server.js
    - /models/User.js
5.- Configurar.
6.- Iniciar: 
    - node app
